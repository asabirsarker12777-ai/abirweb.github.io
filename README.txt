ABIR SARKER — PERSONAL PORTFOLIO

FILES
- index.html: complete responsive website (HTML, CSS and JavaScript in one file)

RUN LOCALLY
1. Extract the ZIP file.
2. Open index.html in Chrome, Firefox, Edge, or another modern browser.
3. Tap the Facebook or Instagram cards to open the profiles.

EDIT
- Open index.html in any code editor.
- Change the title, intro text, or About section directly in the HTML.
- The Facebook and Instagram URLs are included in the social buttons and cards.

PUBLISH ONLINE
Upload index.html to any static website host, such as GitHub Pages, Netlify, or Cloudflare Pages.
The Google Fonts import uses the internet; system fonts will be used if it cannot load.
